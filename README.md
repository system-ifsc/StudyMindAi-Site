# StudyMind AI Site

Site de apresentação do **StudyMind AI**, projeto desenvolvido por **Gabriel Moraes e Gabriel Henrique**.

Plataforma de estudos: [studyminds.vercel.app](https://studyminds.vercel.app).

## Conteúdo

- Início e apresentação do projeto.
- Páginas de projeto, criadores, recursos, aplicativo e dúvidas.
- Temas claro e escuro, com preferência salva no navegador.
- Layout responsivo e animações com suporte a movimento reduzido.
- Captura real do painel demonstrativo na apresentação do Android.
- Link para a plataforma e orientações de instalação da versão web.

O download direto do APK ainda depende de um link de distribuição.

## Abrir localmente

Abra [dist/index.html](dist/index.html) no navegador. Também é possível executar um servidor estático na raiz deste repositório:

```bash
python3 -m http.server 8787 --directory dist
```

Acesse `http://localhost:8787`.

## Publicação

O site usa HTML, CSS e JavaScript, sem dependências ou etapa de build. Configure a hospedagem para servir a pasta `dist`.

Este repositório contém a apresentação do projeto. O backend e o código do aplicativo Android pertencem ao projeto principal.
